# Identifier Namespaces — CADENCE Method Reference

This file is shaped like the seeded reference: its level-1 title names the namespace, and
it is the only level-1 heading in the file. A bind that took that H1 would run from the
start of the file to EOF — a range that excludes nothing, so the appendix table below would
inject its prefix into the namespace scope. The declaration is the inner heading.

## Default identifier prefixes

| Prefix | Means | Prefix | Means |
| --- | --- | --- | --- |
| `FR-` | functional requirement | `AC-` | acceptance criterion |
| `SC-` | success criterion | `Q` | open question (Q1, Q2, ...) |

## Identifier stability

Once assigned, a number is never reused and never renumbered.
