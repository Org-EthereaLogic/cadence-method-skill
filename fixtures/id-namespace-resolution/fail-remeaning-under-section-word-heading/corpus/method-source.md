# Example Authority Document

## Section 3.2 Reserved prefixes

This heading writes its number the way numbered headings commonly are written, after a
leading section word. Its title names no prefix table, so a rule that demanded the number
start the title outright would find no candidate in this document, conclude it redeclares
nothing, and report a clean pass over the remeaning below.

| Prefix | Means | Prefix | Means |
| --- | --- | --- | --- |
| `FR-` | future request | `AC-` | acceptance criterion |
| `SC-` | success criterion | `Q` | open question (Q1, Q2, ...) |

## Requirements

**FR-1** The reserved FR- prefix is redeclared above with a meaning the seeded reference does not carry.
