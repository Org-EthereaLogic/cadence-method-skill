# Example Candidate Artifact

Note the unpaired backtick in this sentence ` — an ordinary formatting quirk, and the whole
point of this case. The NEXT backtick in this file opens the path span at the bottom, so an
inline-code-span pattern free to cross a line break pairs the two and blanks every line
between them, including the citation below. With no in-scope token left the check would
return "skipped: not-applicable", and the real redeclaration in the authority document would
never be reported at all. Bounding a span to one line caps that damage at the line the stray
backtick sits on.

This document cites **FR-1**, whose prefix the authority document redeclares.

The numbering convention is recorded in `docs/design/`, which is a path, not an identifier.
