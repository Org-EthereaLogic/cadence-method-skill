# Example Candidate Artifact

Note the unpaired backtick in this sentence ` — an ordinary formatting quirk,
and the whole point of this case. The NEXT backtick in this file opens the
path span further down, so an inline-code-span pattern free to cross a line
break would pair the two and blank every line between them, including the
seeded broken link below.
